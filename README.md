# Bandura Atelier

A premium interactive Bandura customizer for designing and configuring handcrafted Ukrainian banduras.

## Features

- Interactive Bandura configuration experience
- Nine languages: English, Ukrainian, Spanish, Italian, French, German, Chinese, Japanese and Hebrew
- RTL support for Hebrew
- Wood, finish, strings, ornamentation, electronics and accessories
- Live configuration summary and estimated price
- Responsive design for desktop, tablet and mobile
- Distinct visual identity inspired by Ukrainian craftsmanship

## Vision

Bandura Atelier is a modern digital experience for discovering and configuring the Ukrainian bandura.
